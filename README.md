# Campus Tech

Landing page for Campus Tech @ UIUC, served at **campustech.iguide.chat**.

A static site: the page itself has no build step. The only build is the
one-off bundle of the pull cord in `tools/pullcord/`, whose output is committed
in `vendor/`.

| File | What it is |
| --- | --- |
| `index.html` | Hero (original effect markup), plain-text sections, nav, pull cord mount (hand-written) |
| `past.html`, `privacy.html`, `terms.html`, `articles/` | Sub pages, generated by `tools/pages/build_pages.py` |
| `robots.txt`, `sitemap.xml`, `llms.txt` | Crawler rules, sitemap and an AI-readable site summary (sitemap and llms.txt are generated) |
| `assets/og.png`, `favicon.svg`, `apple-touch-icon.png` | Social preview image and icons (`tools/images/render.py` renders the PNGs) |
| `assets/previews/` | Hover-preview screenshots of outbound links + `manifest.json`, made by `tools/previews/capture.py` |
| `src/style.css` | The original effect's `style.css` verbatim at the top, Campus Tech additions below |
| `src/main.js` | Random colours on click (original), GSAP smooth scrolling, nav behaviour |
| `src/tubes.js` | Starts the tubes and replaces their per-frame cursor logic (see below) |
| `src/dither.js` | Light-mode cursor trail: dithered pixel trail (inspired by Eniyan Raja's DitherCursor) |
| `src/ribbons.js` | Earlier light-mode trail (glossy ribbons), not loaded; swap the import in `main.js` to use it |
| `vendor/tubes1.min.js` | Byte-identical copy of the original effect's vendor file |
| `vendor/gsap.min.js`, `ScrollTrigger.min.js`, `ScrollSmoother.min.js` | GSAP 3.13.0 |
| `vendor/pullcord.js`, `pullcord.css` | Pull cord bundle (React + pullcord), built from `tools/pullcord/`; `tools/pullcord/PullCord.js` is a local copy of the component whose click/Enter animates a real pull |

## Run locally

```bash
python -m http.server 5180
```

Open http://localhost:5180. (ES modules do not load from `file://`.)

## Edit the sub pages and articles

Past, Privacy, Terms and the articles share one template (head with SEO tags and
structured data, nav, backgrounds, scripts). Edit the content in
`tools/pages/build_pages.py`, then regenerate the HTML, `sitemap.xml` and
`llms.txt`:

```bash
python tools/pages/build_pages.py
```

To add an article, add an entry to `ARTICLES` in that file.

## SEO and GEO

- Every page has a unique title and description, a canonical URL, Open Graph and
  Twitter card tags, and the shared preview image `assets/og.png`.
- Structured data (JSON-LD): `Organization` and `WebSite` on the home page,
  `BreadcrumbList` on sub pages, `Article` on articles, and `FAQPage` on the
  recruiting article. Facts in the markup match the visible text.
- `sitemap.xml` lists every page; `robots.txt` allows all crawlers, including AI
  search crawlers (GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot and others).
- `llms.txt` is a plain-language summary (key facts plus links) so AI assistants
  can describe the organization correctly.

## Fill in the placeholders

Placeholders are in `[brackets]` with a faint dashed underline on the page, and
each block is marked in `index.html`:

```bash
grep -n "TODO(campustech)" index.html
```

## How it works

- **Tubes, smooth leave / re-entry.** The stock component jumps the tubes
  between the cursor and an idle orbit in a single frame whenever the pointer
  leaves or re-enters the page. `tubes.js` crossfades between the two and eases
  the target instead. Tune with `ENTER_RATE`, `LEAVE_RATE` and `FOLLOW_RATE`.
- **Small screens.** The idle orbit shrinks to fit narrow viewports, and touch
  events drive the tubes so they follow a finger even while the page scrolls.
- **The canvas parent (`.bg`) is exactly one screen and sits outside the
  scroll content.** The component sizes its canvas to its parent, and
  ScrollSmoother's transform would break `position: fixed` inside the content.
- **Smooth scrolling** uses GSAP ScrollSmoother (`smooth: 1.2`); phones keep
  native momentum scrolling. Section lines fade up as they enter the screen.
- **Nav** is centred at the top on full-size screens (left-aligned on phones,
  clear of the cord). It is visible while the page is still, fades out while
  scrolling, and returns half a second after scrolling stops.
- **Link previews** sit centred above the hovered link text (below it when
  there is no room above).
- **Light mode** is the pull cord at the top right (drag it down, click it, or
  focus it and press Enter). The choice is remembered in `localStorage`. The
  neon tubes rely on glow and metal reflections that only read on dark, so light
  mode swaps them for `src/dither.js`: a soft trail behind the cursor rendered as
  crisp single-colour dots with an 8x8 Bayer dither, dissolving dot by dot when
  the pointer rests. A click recolours it (in dark mode a click recolours the
  tubes). Hiding the tubes' layer with `display: none` also pauses their renderer.

Append `?debug` to the URL to expose the tubes' internals as `window.__tubes`.
If WebGL is unavailable or the visitor prefers reduced motion, a static
gradient replaces the effect and smooth scrolling is off.

## Refresh the link previews

Hovering an outbound link (with a mouse) shows a screenshot of that site. Most
sites refuse to load in an iframe, so the screenshots are static. After adding
a link or when a linked site changes:

```bash
python tools/previews/capture.py
```

It needs Chrome and Pillow, captures in English with a signed-out profile, and
skips codepen.io (Cloudflare blocks headless Chrome there).

## Rebuild the pull cord

```bash
cd tools/pullcord
npm install
npm run build
```

## Deploy

- **GitHub Pages:** push to `main`, enable Pages from the repo root. `CNAME`
  already holds `campustech.iguide.chat`; add a `CNAME` DNS record pointing
  `campustech` to `<user>.github.io`.
- **Cloudflare Pages:** connect the repo, no build command, output directory
  `/`, then add `campustech.iguide.chat` as a custom domain.
